# Segmentation maturity assessment

**A reproducible, 100-point maturity score for every workspace in a Cisco Secure Workload
deployment — and the prioritized roadmap to move from visibility to full enforcement.**

## The opportunity

Most CSW deployments plateau: agents installed, some workspaces analyzed, few enforced.
The customer bought micro-segmentation and is running visibility. Moving the estate to
enforcement is a services journey — but first someone has to measure where each
workspace actually stands, consistently, across hundreds of workspaces.

## What's included

1. **Bulk maturity scoring (automated)** — every workspace in a scope scored on a
   9-criteria, 100-point model: primary workspace, analysis enabled, analyzed version,
   policy count, catch-all action, DENY rules, protocol specificity, enforcement enabled,
   enforced version. Five maturity levels from MINIMAL to MATURE.
2. **Deep-dive per workspace** — detail card with policy breakdown (ALLOW/DENY,
   TCP/UDP/ANY), criteria table and score.
3. **Prioritized enforcement roadmap** — which workspaces are one step from enforcement,
   which need policy work first, which are risks (catch-all ALLOW with enforcement on).
4. **Progress tracking** — the score is deterministic; quarterly re-runs turn the roadmap
   into a measurable program the partner can sell as recurring service.

## Deliverables

- Maturity scorecard for the full estate (per-workspace scores + level distribution)
- Top-N enforcement candidates with the specific gap each must close
- Executive readout

## Typical engagement

1–2 weeks for the initial assessment and roadmap; quarterly re-assessments as follow-on.

## How the toolkit accelerates it

The scoring methodology is codified in the toolkit's AI mode: one question ("assess the
maturity of every workspace in scope X") produces the full scorecard with consistent
scoring — the same rubric every time, for every engineer, at every customer.

## Customer prerequisites

- CSW API credentials (read-only)
