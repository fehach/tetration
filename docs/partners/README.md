## Engagement model

1. **Discovery call** — scope, deployment size, timeline.
2. **Automated assessment** — the toolkit collects the evidence in hours, not weeks.
3. **Expert analysis & delivery** — findings, prioritized roadmap, executive readout.
4. **Optional follow-on** — implementation, migration execution, managed operation.

Every engagement produces artifacts the end customer keeps: reports, evidence CSVs,
runbooks, and (where applicable) the reproducible scoring so progress can be re-measured.

## Why an AI-assisted toolkit matters to a partner

- **Speed**: evidence collection that takes a consultant days of clicking is one command.
- **Consistency**: deterministic scoring — two engineers get the same result, engagements
  are comparable across customers and quarters.
- **Margin**: junior engineers deliver senior-quality assessments with guardrails
  (AST sandbox, read-only defaults, destructive-action confirmation).
- **Differentiation**: an AI copilot demo in the first meeting is a conversation starter
  competitors don't have.
